# Анализ отрасли 41.20 (Строительство жилых и нежилых зданий)

Проект представляет собой пайплайн для анализа финансового состояния компаний малого и среднего бизнеса в строительной отрасли. 

## Что делает проект:
1. **Сбор данных:** Парсит реестр ФНС, фильтрует юридические лица по ОКВЭД 41.20.
2. **Финансовый анализ:** С помощью API ФНС (bo.nalog.gov.ru) собирает данные бухгалтерской отчетности и рассчитывает показатель **EBIT** (стр. 2300 + стр. 2330) за 2021–2025 гг.
3. **Геокодирование:** Определяет юридические адреса и координаты (широта/долгота) Топ-100 компаний по среднему EBIT. 
   *Примечание: Для соблюдения лимитов API и безопасности, этап геокодирования через DaData был выполнен один раз, результат сохранен в файл `top100_with_coords.csv`.*
4. **Визуализация:** 
   - Строит график суммарного EBIT по годам.
   - Строит гистограмму распределения роста EBIT (относительно 3 лет назад).
   - Наносит компании на интерактивную карту (Folium) и статичную карту (GeoPandas).

## Структура проекта:
- `main.py` — главный скрипт для запуска.
- `parsing.py` — модуль для работы с API ФНС и DaData.
- `plots.py` — модуль для построения графиков и карт.
- `cleaned_reestr.csv` — отфильтрованный реестр компаний.
- `top100_with_coords.csv` — данные по Топ-100 компаниям с координатами.
